# T115 The game gets its own icon

Back to [the plan](../Plan.md). This task's title line, **Model and effort**, **Depends on**, **Needs**, **Touches** and any **Waiting:** or **Blocked:** line are in its entry there, under "Open".

## Task

- **Why:** my request on 2026-11-19, with the itch.io media (T113): the game should have its own icon. The packaged game still shows Unreal's default icon on its `.exe`, its window and its taskbar button. The itch.io page has no icon of its own (its thumbnail is the cover, T113), so this icon is the one on the player's computer.
- **What makes it good:**
  - **One bold shape that reads at 16 × 16.** The hook in one picture is a good start: the costume's teal cardboard head, with the person's eyes peeking through the slots and the drawn smile. A better idea is welcome.
  - **The game's own look.** Make it from an in-engine render of the game's own model (a close-up in flat, bright light), simplified and cleaned up in 2D, on a solid color from `UIStyle`. Ask me before any paid generation.
  - **Readable on light and dark.** The taskbar and Explorer can be either.
- **Steps:**
  1. **Find where the icons go.** Find where UE 5.8 reads each platform's icon for a packaged game: the engine's own default files and the project overrides under `Build/<Platform>/`. Check that this Blueprint-only project's build picks them up (packaging compiles a small game program here, so the Windows `.ico` should be built into the `.exe`). Write what you find under "## Findings".
  2. **Design.** Make three candidates. Look at each at 16, 32, 48 and 256 px, on a light and a dark background. Show me all three and ask me to pick one.
  3. **Make the files.** Keep the source at 1024 × 1024, the candidates and how they were made in `Docs/Art/Icon/`. Write `Build/Windows/Application.ico` with the sizes Windows uses (16, 20, 24, 32, 40, 48, 64, 128 and 256). Make the Mac icon where 5.8 reads it too; if it is an `.icns` file, add an LFS rule for it to `.gitattributes` first. If an icon needs a project setting, edit `Config/Default*.ini` with the editor closed.
  4. **Check.** Package a Windows build into `Packaged/` (the command is in `Docs/Builds.md`). Explorer shows the icon on the `.exe`, and the running game shows it on its window and its taskbar button. The Mac icon can be checked only in a Mac build: write it under "## Findings" as unchecked, for the next Mac build (T92).
  5. **Record it.** Add the icon to `Docs/Assets.md`: what it is, what it was made from and how.
- **Done when:** `Build/Windows/Application.ico` is in git with every size, and a packaged Windows build shows it on the `.exe`, the window and the taskbar button; the Mac icon file is where 5.8 reads it; the source and the candidates are in `Docs/Art/Icon/`; and I have picked the icon.
