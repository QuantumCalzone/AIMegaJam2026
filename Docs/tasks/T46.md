## Findings

### Decisions made for my person

- **Height: about 1.6 m to the top of the capsule, not waist-high.** The design says "waist-high clay capsule". I kept the bots about as tall as T17's (capsule top at 158 cm, toppers to about 220 cm, labels at 228 cm), because the house camera, the labels, the prop slots in `Receive` (hand at the arm pivot minus 44 cm, head at 160 cm, back at 106 cm) and T38's planned bubbles are all set for that height, and smaller bots would read small from the house. T49 can scale the five robot actors if the opera house wants them smaller.
- **The seam ring is in the seat color,** as the lip of the top half, so the top half reads as one cap. The design names only "a raised seam ring".
- **Arms, feet and the antenna stalk are charcoal clay** (`MI_Clay_Charcoal`), and the mitten hands are in the seat color. The design gives no color for them.
- **Cream is `MI_Clay_Cream` (0.66, 0.55, 0.38) linear,** a step darker than the #F2E3C6 I first tried, because the stage spotlight washed the brighter cream to white.
- **Only the worrier and the overclocker have brows,** as before. The design says every bot has eyebrows; T17 gave brows to those two only, and the task said to keep the face as it is.
- **The cut bot's cream half stays cream.** On the cut, the top half, seam, hands, eyes, brows and mouth go gray or dark (as before); the bottom half doesn't change.

### Unreal MCP and editor rules found in this task

- **The editor's console runs Python, and that reloads an asset from disk.** No MCP tool reloads, but `SlateInspectorToolset.Type` into the status bar's console box (`Cmd`, a textbox in the snapshot) with `py "<absolute path>.py"` runs an editor Python file. `unreal.EditorLoadingAndSavingUtils.reload_packages([unreal.load_package(p) ...], unreal.ReloadPackagesInteractionMode.ASSUME_POSITIVE)` reloaded `BP_Show` and `WBP_Stage` (result `(True, "")`; the warnings name only objects the new version removed). Python's `unreal.log` lines land in the editor log; write results to a JSON file under `Saved/` to read them back.
- **Editor Python edits a Blueprint's components well.** `unreal.SubobjectDataSubsystem.k2_gather_subobject_data_for_blueprint(bp)` gives the handles; `SubobjectDataBlueprintFunctionLibrary.get_object_for_blueprint(get_data(h), bp)` gives each component template to `set_editor_property` (`relative_location`, `relative_rotation` with `unreal.Rotator(roll=, pitch=, yaw=)`, `relative_scale3d`, `static_mesh`, `override_materials`, `component_tags`, `visible`). `add_new_subobject(unreal.AddNewSubobjectParams(parent_handle=, new_class=, blueprint_context=))` plus `rename_subobject(h, unreal.Text(name))` adds one; `delete_subobject(root_handle, h, bp)` removes one. Then `unreal.BlueprintEditorLibrary.compile_blueprint` and `EditorAssetLibrary.save_asset`. Component variables (`GetMouth`, `GetSeam`) work in the DSL after that.
- In this Python, `override_materials` and `component_tags` are read with `get_editor_property`, not as attributes; `unreal.LevelEditorPlaySettings` isn't exposed (use `ObjectTools.set_properties` on `/Script/UnrealEd.Default__LevelEditorPlaySettings`); `Actor.rerun_construction_scripts` doesn't exist (setting the instance properties after `spawn_actor_from_class` was enough).
- **T17's re-place rule still holds:** template edits didn't reach the robots in the level until they were destroyed and spawned again (`EditorActorSubsystem.destroy_actor`, `spawn_actor_from_class`, then `Seat`, `FallDir`, `PreviewPersona`, label and folder). A material instance change reaches them with no re-place.
- **`AssetTools.read_file` reads only `.csv .html .json .md .py .txt`**, so name expanded DSL files `.txt`.
- **`CaptureViewport` needs an `annotations` object** even when unused (grid and labels at 0, `classFilter` null), and its image is too big for a tool result: save the base64 with `AssetTools.write_file` inside the same script and decode it locally.
- **`M_Clay` on engine shapes:** `ThumbScale` 0.5 with `ThumbDepth` 0.5 looked like terry cloth; `ThumbScale` 0.12 with `ThumbDepth` 0.35 reads as clay at shapes scaled 0.7.
