#### Unreal MCP rules found in this task

- **`AssetTools.read_file` needs an absolute path.** A relative `Saved/...` path resolves against the engine's `Binaries/Win64` folder and fails as outside the allowed roots.
- **`create_node` takes the `type_id` that `find_node_types` returns** (`CallFunction|EndReveal`), not the `|RevealEnd` form `get_node_infos` shows for an existing self call. `find_node_types` needs `type_id_filter` and `context_pins` (an empty list works).
- **`AssetTools.save_assets` takes `asset_paths`** (package paths such as `/Game/NHOS/Core/BP_Show`), not `assets`.
- **`connect_pins` from an exec output that already has a link replaces that link,** so inserting a node takes two `connect_pins` calls and no `break_pins`.
- **Slate `Click` goes to a screen position.** On this PC another window came over the PIE window mid-show, and every click on "Start the scene" landed on it and did nothing. Calling `Windows` with `action` `select` on the PIE window before each click fixed it. `PressKey` Enter reached Play Again only after the PIE window had been clicked once; the first time it went to the editor.
- **Clicking a vote button and then `Type` in the same `execute_tool_script` doesn't work:** Send enables a frame later, and no frame passes inside a script. Click in one call and type the reason in the next.
