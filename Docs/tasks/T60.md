#### Unreal MCP rules found in this task

- **A second editor on the Mac works:** open the editor binary on a worktree's `.uproject` with `-ModelContextProtocolPort=8011 -NoLiveCoding`; it listened on 8011 about 3 minutes after launch (the worktree needed `git lfs pull` first: a fresh worktree has LFS pointers, not assets). Talk to it with plain JSON-RPC over HTTP (`initialize`, then `tools/call` with the `Mcp-Session-Id` header). Its log is `~/Library/Logs/Unreal Engine/AIMegaJam2026Editor/AIMegaJam2026_2.log` (the `_2` because the first editor holds `AIMegaJam2026.log`), not the worktree's `Saved/Logs/`.
- **`ObjectTools.set_properties` takes `values` as a JSON string,** not an object. Passed an object, it returns without an error and sets nothing.
- **`AssetTools.save_assets` fails during PIE** ("Asset does not exist"). Stop PIE, then save.
- **Calling a widget function at run time:** type `ke <Class>_C <Function> <args>` into the editor's status-bar Cmd box (`SlateInspectorToolset.Type` into that textbox without `submit`, then `PressKey Enter`). `ke` takes a class name and calls every instance; quote an argument with spaces. `Type`'s `submit` sends Enter to the PIE window's focused widget instead (it pressed Play Again once), and the first command typed after switching windows can lose its Enter, so send a throwaway command first.
- **PIE window sizes on a Retina Mac are pixels:** `newWindowWidth` 1600 × `newWindowHeight` 900 gives a 1600 × 968 screenshot (title bar included), as in T33, when `newWindowPosition` is set and `centerNewWindow` is off. With `centerNewWindow` on, the window opened at the full screen width instead. `r.SetRes` doesn't resize a PIE window. `SlateInspectorToolset.Windows` lists the windows in focus order, so pick the PIE window by its title.
