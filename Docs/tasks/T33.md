#### Unreal MCP rules found in this task

- **On this Mac, `SlateInspectorToolset.Click` never lands** (Retina display). The snapshot reports a widget's position as the window's position in points plus the widget's offset in pixels, and the click goes to that point, so it misses. Moving the PIE window to the screen's top-left didn't help. `PressKey` and `Type` work, because they go to the focused widget: make buttons focusable and drive them with Tab and Enter.
- **To keep a screenshot without `AssetTools.write_file`:** return the image's base64 from `execute_tool_script` (`{'b64': r['data']}`). The result is too big for the tool, so Claude Code saves it to a file in the session's `tool-results` folder; decode that file to a PNG. `SlateInspectorToolset.Screenshot` of the PIE window is full resolution (1600 × 968 for a 1600 × 900 window, title bar included).
- **`screencapture -l<id>` fails** in this session ("could not create image from window"): the shell has no screen-recording permission. `CGWindowListCopyWindowInfo` with `.optionOnScreenOnly` lists no editor window; `.optionAll` does.
- **A Blueprint function library must be loaded before a graph can call it.** In a fresh editor session, `write_graph_dsl` failed with "`Class|UIStyle|UISize` does not exist" until `BlueprintTools.list_functions` on `UIStyle` loaded it.
- **`get_node_type_pins` adds the node it describes to the graph.** Only use it on a graph you rewrite next.
- **`AssetTools.read_file(file_path)` reads a file from disk inside a script,** so a DSL source can go to `write_graph_dsl` without passing its text through the tool call. `Tools/dslpp.py` needs a `;;; GRAPH <Name>` line before each graph.
- `add_object_function_param` and `add_function_param` take no `container_type` for a single value (leave it out; `"None"` fails). `set_properties` merges a partial struct: `{"widgetStyle":{"backgroundImageNormal":{"drawAs":"NoDrawType"}}}` changed only that field.
- `UserInterface|EventDestruct` runs when `RemoveFromParent` removes the widget. `Widget|SetRenderOpacity` takes `InOpacity`; `Widget|AddChildToUniformGrid` returns the slot (`Content`, `InRow`, `InColumn`); `Layout|UniformGridSlot|SetHorizontalAlignment` takes `InHorizontalAlignment`.
- PIE play settings live on `/Script/UnrealEd.Default__LevelEditorPlaySettings` (`newWindowWidth`, `newWindowHeight`, `centerNewWindow`, `newWindowPosition`, `gameGetsMouseControl`). This task put them back as it found them.
