# T36 Each burning bill shows the logo of the provider it paid

Back to [the plan](../Plan.md). This task's title line, **Model and effort**, **Depends on**, **Needs**, **Touches** and any **Waiting:** or **Blocked:** line are in its entry there, under "Open".

## Task

- **Why:** my request on 2026-11-15. Since T35, a robot head sits in each burning bill's round medallion. If the medallion shows the logo of the company that the reply was paid to, I can see who is spending my money.
- **Steps:** steps 1 and 2 need no editor and change no `.uasset`, so they can run as a prep piece at any time.
  1. **Find the logos.** Get one logo for each provider id in `Content/NHOS/Data/llm.json`: `anthropic` (Anthropic), `openai` (OpenAI), `xai` (SpaceXAI, the name on screen) and `meta` (Meta).
     - Use the company's own logo, not a product's logo (not Claude, ChatGPT, Grok or Muse), because product names stay off the screen.
     - Take each logo from the company's own brand or press page. Prefer a vector file (SVG) or its largest PNG.
     - Read each company's brand rules before you use its logo. If a company's rules don't allow this use, or SpaceXAI has no logo of its own, stop and ask me.
     - Before you download a file, ask me and give the file name, the source and the size.
  2. **Make a badge for each logo.** Make one 128 × 128 PNG for each provider, `Docs/MoneyBurnArt/logo_<id>.png`:
     - A filled circle in the medallion's color, #687D6C, with the logo on it in the bill's ink color, #354942. The logo is about 70% of the circle's width, centered. The outside of the circle is transparent. This keeps the bill's engraved look (the colors are in `Docs/MoneyBurnArt.md`, "Colors").
     - If a company's rules don't allow a recolor, use that company's own one-color version of the logo instead.
     - Add to `Docs/MoneyBurnArt.md` how you made the four files, so they can be made again.
     - Add each file to `Docs/Assets.md`. A logo is a trademark, not a licensed asset. In its license column, write "Trademark of <company>, used only to name the provider. <brand page link>, read on <date>."
  3. **Import the badges** next to the bill art, into `Content/NHOS/UI/MoneyBurn/`, as `T_Logo_anthropic`, `T_Logo_openai`, `T_Logo_xai` and `T_Logo_meta`. Use the same settings as `T_Bill`: the UI texture group, no mipmaps and `TC_EditorIcon` compression. `TextureTools.import_file` imports a PNG (see the T35 findings in [T35.md](T35.md)).
  4. **Show the logo on the bill.** In `WBP_BurningBill`:
     - Add an image, `LogoImg`, with the same size and position as the medallion, so that it covers the robot head.
     - Put `LogoImg` above `T_Bill` and below the char clip in Z-order. Then the char wipe covers the logo as the bill burns.
     - Add a function, `SetLogo(Prov)`. For a known provider id, it sets the brush of `LogoImg` to that provider's texture and shows `LogoImg`. For all other values, the empty string included, it hides `LogoImg`, so the robot head shows as it does now.
  5. **Send the provider to the bill.**
     - The two callers of `BPC_LLMClient.Burn` set `CurProv` before they call it. `HandleHttp` (the relay, through `BurnPaid`) sets it from the pending ask. `FlushLocal` (Test for Free with `burn_test` on) sets it for each free ask. Make sure that nothing between the `set` and the `Burn` call changes `CurProv`.
     - `CurProv` is the provider that the ask was really sent to, after the fallback in `RoleProvider`, so the logo is always true. The input LLM and the Director run on `anthropic` (`llm.json`), so their bills show Anthropic's logo. That is also true, because Anthropic is paid for those replies.
     - Thus `Burn` can pass `CurProv` on, and `HandleHttp`, `BurnPaid` and `FlushLocal` do not change. `BPC_LLMClient.Burn(Tag)` prints `NHOS: BURN <tag> provider=<id>` and calls `WBP_MoneyBurn.Burn(Prov)`. `WBP_MoneyBurn.Burn` calls `SetLogo(Prov)` on each new bill immediately after it creates the bill.
     - Start from the pushed `Graphs/BPC_LLMClient/Burn.txt` and `Graphs/WBP_MoneyBurn/Burn.txt`. Commit them and the new `Graphs/WBP_BurningBill/SetLogo.txt` with the task.
- **Done when:**
  - A free autoplay show with `burn_test` on reaches `NHOS: SHOW END`. Each `NHOS: BURN <tag> provider=<id>` line has the same provider as the `NHOS: LLM <tag> ok ... provider=<id>` line for that tag, and the lines include all four providers.
  - Screenshots at 1600 × 900 show a burning bill with each of the four logos, and each logo is clear at that size. One screenshot taken during a burn shows the char covering the burnt part of the logo.
  - I watch one free show with `burn_test` on in a game window, and I say that I can tell which company each bill paid. Then set `burn_test` back to `false`.
