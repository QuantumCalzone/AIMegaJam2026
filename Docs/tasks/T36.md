### Unreal MCP rules found in this task

- **`Appearance|SetBrushfromTexture` in the DSL is `UBorder`'s node** (the first of two with that name), so it won't take an Image. For an Image, write `(Class|Image|SetBrush :self <img> :Brush (Widget|Brush|MakeBrushfromTexture :Texture "<path>" :Width 38 :Height 38))`; it reads back as `Appearance|SetBrush`, the Image's setter. `get_node_type_pins` shows which class a node's `self` takes.
- **`UMGToolSet.AddWidget`'s `childIndex` counts the parent's children only**, not the depth-first list that `GetWidgetDescription` prints. `MoveWidget` fixes a wrong place, but it makes a new slot (`CanvasPanelSlot_8` here); the slot's layout carried over.
- **A function's new input exists for the DSL only after a compile,** as T19 found: `add_function_graph`, `add_function_param` (type `string`), `CompileWidgetBlueprint`, then `write_graph_dsl`.
- **Free-mode bills burn in bursts**: a scene's or round's asks answer together, about 0.3 s apart at most, so a screenshot loop catches bills only around the start of each phase.
