### Unreal MCP rules found in this task

- **A function named `SetX` beside a variable `X` reads back ambiguously:** `read_graph_dsl` shows the call to the function `SetWinReason` as `(Variables|Default|SetWinReason Win)`, the same form as a setter of `WinReason`. The nodes are right (`get_node_infos` shows a `K2Node_CallFunction`, and the setters inside the function are `K2Node_VariableSet`). Prefer a function name that isn't `Set` plus a variable's name.
- **Never stop a game window with `taskkill /FI "WINDOWTITLE eq AIMegaJam2026*"`:** the editor's window title ("AIMegaJam2026 - Unreal Editor") matches too. This session killed the repo folder's editor that way (after `BP_Show` was saved, so the task lost nothing), and probably another session's worktree editor, then reopened the repo folder's editor. Find the game window's PID with `Get-CimInstance Win32_Process` (its command line has `-game`) and use `taskkill /F /PID <pid>`.
- **A floating PIE window takes its size from `/Script/UnrealEd.Default__LevelEditorPlaySettings`** (`newWindowWidth`, `newWindowHeight`). After an editor restart it was 1280 × 720.
- **`SlateInspectorToolset.Screenshot` called directly through `call_tool`** comes back too big for the tool, and Claude Code saves it as JSON in the session's `tool-results` folder; decode `returnValue.data` to a PNG. Select the PIE window first with `Windows` (`action` `select`, its index).
