# T53 Scene clock: one scene fewer than the cast, on a clapperboard

Back to [the plan](../Plan.md). This task is done.

## Task

- **Model and effort:** Opus 5.5, high. The show's length and its end check change, and a new piece goes on the in-show screen.
- **Depends on:** T59 (the lock on `BP_Show`), T30 (the lock on `WBP_Stage`)
- **Needs:** editor + Unreal MCP running, Test for Free for the PIE shows.
- **Touches:** `Content/NHOS/Core/BP_Show.uasset` (`SceneCount` in `SetupShow`, the end check after the reactions, the scene banner's text), `Content/NHOS/UI/WBP_Stage.uasset` (the clapperboard), `Content/NHOS/Data/prompts.json` (`game`), `Tools/check_prompts.py` (`show.scenes`), `Graphs/` files for the graphs it writes, `Docs/tasks/T53.md`.
- **Why:** design change 4 of 12 (2026-11-15). The number of scenes is the cast size minus one: 4 scenes with 5 actors, 3 with 4. That includes one spare scene, which a tie uses up (T52). The show ends when two actors remain or after the last scene, and a clapperboard on screen shows "SCENE n / total". Today `SceneCount` is the seat count minus 2, and a show ends only when I am cut or two actors remain. The rule is in the design doc's Rules tab ("Cast & personas", "The Cut" step 6).
- **Steps:**
  1. **`BP_Show`:** `SceneCount` = the cast size − 1, where it is set in `SetupShow`. `show.scenes` in the state the AIs read follows it. Update the scene banner's "Scene n of m" text if it needs it.
  2. **The end check:** after a scene's last step (the reactions, or a tie once T52 is in), end the show when two actors remain or when `SceneNum` equals `SceneCount`. I am still on stage in both cases, so both call `EndShow` as a win. Until T52 lands, every scene cuts one actor, so the last scene is never reached; T52's check plays it.
  3. **The clapperboard in `WBP_Stage`:** a small clapperboard in a corner that shows "SCENE 2 / 4" in every phase from Scene Prep to the reactions. Follow T32's style Blueprint. Give it its own function, for example `SetClapper(Scene, Total)`, called where the scene number changes.
  4. **`prompts.json` `game`:** "How a show works" says how many scenes a show has and when it ends. `Tools/check_prompts.py` builds `show.scenes` the same way.
  5. **Check:** a free autoplay show with 5 actors prints `scenes=4` in its `SETUP` line (add the field if it is missing) and sends `"scenes": 4` in the state; one with 4 actors gives 3. Screenshots of the clapperboard in Scene Prep and in a scene turn.
- **Done when:** the check passes and both shows reach `NHOS: SHOW END`.
- **Result:** done on 2026-11-15. A show has one scene fewer than the cast (4 with 5 actors, 3 with 4) and ends after its last scene as well as at the final two (`BP_Show.LastSceneDone()`). A clapperboard under the header reads `SCENE n / total` from Scene Prep to the reactions, and the banner reads "Scene n: <title>" or "Last scene: <title>". Free autoplay shows with 5 and 4 actors reached `SHOW END` with `scenes=4` and `scenes=3` in their `SETUP` lines and in the state the AIs read.

### Unreal MCP rules found in this task

- **A game window started from the editor binary keeps the `.uasset` files it loaded open.** Saving `BP_Show` while a `-game` window ran failed (`MoveFile ... Error Code 32`, "failed to save"), and `save_assets` returned false. Close the game window first (match its `-log=` name in the process command line, so the editor itself is spared).
- **`create_node` type ids:** the integer subtract is `Utilities|Operators|Subtract` (it shows as `Math|Integer|int-int` once made; that id can't be created); also `Math|Integer|Min(Integer)`, `Math|Boolean|ORBoolean`, `Utilities|String|Append` (then `add_node_pin` for a third pin), `Variables|Default|Get<Var>`, `CallFunction|<own function>` and `Class|WBPStage|<WBP_Stage function>`. `find_node_types` needs `context_pins` (pass `[]`).
- **`find_nodes` titles** are the function name without spaces for call nodes (`ShowBanner`, `SetInfoTop`, `LastSceneDone`, `PrintString`), but `Get SceneCount` and `Set SceneCount` for variables and `Branch` for branches.
- **A Python `'\b'` in a script that edits a file is a backspace.** It broke a regex in `check_prompts.py` until `cat -A` showed the `^H`; use raw strings.
- **`UMGToolSet.WrapWidgets`** gives the wrapper the old widget's slot (padding, alignment) and the wrapped widget a fresh slot with padding 0, so the wrapped widget doesn't move. `RenameWidget` names the wrapper.
- **A widget's render shear** sets with `set_properties` on `renderTransform`: `{"translation":{"x":0,"y":0},"scale":{"x":1,"y":1},"shear":{"x":-20,"y":0},"angle":0}`.
