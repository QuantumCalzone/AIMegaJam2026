## Task

- **Why:** design change 3 of 12 (2026-11-15). One actor with the most votes is cut. Any tie for the most votes cuts nobody, but the scene still counts. So I can try to split the vote, and the bots have to agree on a suspect. The rule is in the design doc's Rules tab ("The Cut", step 3).
- **Steps:**
  1. **Ask me first:** the Rules tab doesn't say whether the reactions run after a tie. Ask me with the question tool; the default I'd expect is no reveal and no reactions, straight to the next Scene Prep.
  2. **`BP_Show`, `Tally`:** on a tie for the most votes, cut nobody. Add a game message that the AIs read, for example "The vote is tied between Player 2 and Player 4. Nobody is cut.", show the moment on the banner, and print `NHOS: TIE ... cut=none`. Don't call `AskDirector`; T55 removes the Director's functions afterwards.
  3. **After a tie:** the scene counts. Go on to the next Scene Prep, or to the show's end if this was the last scene (T53's end check). Check that every later phase starts in a good state after a scene with no cut: the cast list, the stamp, the vote row and the reactions' state.
  4. **`prompts.json` `game`:** copy the doc's line "A tied vote cuts nobody and still uses up a scene. If the human is still on stage when the last scene ends, the human wins." word for word, and change The Cut's line that says the Director breaks ties.
  5. **`Docs/switches.example.json`:** `force_tie` now gives a scene with no cut; say so in `_readme`. Update `Tools/check_prompts.py` if it builds a tie's game message.
  6. **Check:** with `force_tie` on, a free autoplay show plays every scene with no cut and ends after the last one with `NHOS: SHOW END result=win`. With it off, a show still cuts one actor per scene. No ask goes out under a `director-` tag in either run.
- **Done when:** the check passes, with a screenshot of the tie banner.
