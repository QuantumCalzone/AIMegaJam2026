### Unreal MCP rules found in this task

- **`ObjectTools.get_properties` takes `instance` and `properties`; `set_properties` takes `instance` and `values`, a JSON string.** A TextBlock's text sets as `{"text": "..."}`; copying `font` and `colorAndOpacity` from one TextBlock's `get_properties` result to another works as is.
- **`AssetTools.write_file` takes only `.csv`, `.html`, `.json`, `.md`, `.py` and `.txt`.** Write a screenshot's base64 to a `.txt` and decode it in Bash.
- **A running PIE actor's variables can be read** with `ObjectTools.get_properties` on `/Game/NHOS/Maps/UEDPIE_0_L_Stage.L_Stage:PersistentLevel.BP_Show_C_0`. That checks run-time state with no print node.
- **`set_pin_value` takes a real newline in the value** (`\n` in the JSON string), and `read_graph_dsl` then prints it raw, which breaks a line-by-line read.
- **`UMGToolSet.AddWidget`** takes `widgetBlueprint`, `widgetClass` (`/Script/UMG.HorizontalBox`, `/Script/UMG.TextBlock`), `widgetDisplayName`, `parentWidget` and `childIndex` (-1 appends), and returns `widget` and `slot`.
- **A Free Talk or reaction turn in PIE:** the prompt reads "Watch the stage. Your turn comes next." until the lines before mine have played; Send is disabled until it reads "YOUR TURN". The vote row's buttons are named by provider (`SpaceXAI`, `Anthropic`, ...); I avoided the fourth button because of T32's bug (it votes for the third name).
