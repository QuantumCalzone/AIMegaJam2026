#### The style Blueprint and the shared pieces

- **`/Game/NHOS/UI/Style/UIStyle`**, a Blueprint Function Library. Any Blueprint calls its functions as `Class|UIStyle|<Function>`. The functions are impure (MCP can't mark a function pure), so bind each result before you use it. Sources in `Graphs/UIStyle/`.
  - `UIColor(Role)`: the doc's palette by role (Ink at 92%, InkSolid, OldGold, Paper, PaperText, PaperQuiet, Gold, Red, Amber, Text, Quiet) plus the state colors the doc lacks (Inset, Raised, and `.Hover` / `.Pressed` for Gold, Red, Paper, Raised). Linear values; each line's comment has the doc's sRGB hex. An unknown role returns magenta.
  - `SeatColor(Name, Fallback)`: OpenAI, Anthropic, SpaceXAI, Meta, You.
  - `UISize(Role)`: the type scale (Caption, Action, Hint 18; Body, Speech, Name, Button, ButtonInk 20; CardTitle 24; Header 32; Banner 48; Result 72; Stamp 120), the spacing steps S1 to S7 (4, 8, 12, 16, 24, 32, 48) and Edge 24, and component sizes (button height 48, radius 12, outline 3, padding 20/8, press drop 2; panel radius 16, trim 2, card trim 3; input outline 2; focus ring 3; seat bar 6; tag radius 10; text outline 2; opacities 0.92, 0.4, 0.12).
  - `UITime(Role)`: Hover 0.12, Panel 0.25, Shrink 0.4, Banner 4, StampIn 0.2, StampHold 3.5, StampFade 1.
  - `UIFont(Role)`: `F_UI` at the role's size. Display roles (Header, Banner, Button, Result, Stamp) are Bold with a 2 px ink outline, the doc's fallback until a display face is imported; ButtonInk is Bold without the outline (dark labels); Name and CardTitle Bold; Action Italic; the rest Regular.
  - `Brush(Fill, Outline, Width, Radius)`: a rounded box with an outline.
  - `ButtonStyle(Kind)` and `MakeButton(...)`: four kinds, Primary (gold, ink text), Secondary (raised plum, quiet outline, white text), Danger (curtain red, white text) and Paper (cream, dark text), each with all four states: hover brightens the fill and lights the outline, pressed darkens it and drops the label 2 px, disabled is 40% with no outline.
  - `StyleButton(Button, Label, Kind)`: the call every button makes. It sets the four brushes, the display font on the label (no outline on Primary and Paper), and makes the label follow the button's state color.
  - `StylePanel(Panel, Look)`: Ink, Paper or Note.
- **`/Game/NHOS/UI/Style/WBP_UIStyleSheet`**, a dev-only board the game never creates. Its PreConstruct styles everything, so the widget designer shows each button kind in all four states (Normal and Disabled are real buttons; Hover and Pressed are borders drawn with the style's own Hovered and Pressed brushes, since a screenshot can't hold a real button in those states), the three panel looks, an AI chat line and mine, and the banner type. Screenshot: `Saved/T32/shots/sheet_window.png`. T33 and T34 can open it to see the shared pieces.

The display face (Lilita One) isn't imported: MCP can't import a font (T14), and the doc allows `F_UI` Bold with the outline. Swapping it later changes one value in `UIFont`.

#### Unreal MCP rules found in this task

- **`BlueprintTools.create` can't make a Blueprint Function Library.** With `asset_type` `/Script/Engine.BlueprintFunctionLibrary` it opens a modal "Cannot create a blueprint based on the class" dialog in the editor and the call hangs until someone clicks OK. Instead, `AssetTools.duplicate` an engine library (`find_assets` with tag `BlueprintType` = `BPTYPE_FunctionLibrary` finds three, such as `/PCG/BP_Elements/Resources/RenderTargetFunctions`) into `/Game` and `remove_function_graph` every function.
- **A function library's functions don't show in `find_node_types` from other Blueprints** (nor `get_node_type_pins` under `CallFunction|`), but `Class|UIStyle|<Function>` creates the call. Inside the library itself they are `CallFunction|<Function>`.
- **`add_function_graph` functions are impure, and MCP can't make them pure:** the entry node's `ExtraFlags` can't be read or set.
- `ObjectTools.list_properties` on a K2 node returns nothing useful; on a widget or slot it lists camelCase names (`bOverride_WidthOverride`, `widthOverride`, `horizontalAlignment`).
- `Appearance|SetBrush` resolves to the Border's `SetBrush` (its `self` is a Border); check with `get_node_infos`.
- `Class|TextLayoutWidget|SetAutoWrapText`'s pin is `AutoWrapText`. `Math|Float|Truncate` (not `Math|Conversions|Truncate`). A widget's PreConstruct is `(event UserInterface|EventPreConstruct (IsDesignTime) ...)`.
- `get_node_type_pins` results have `name`, `type_id` and `value`, not `type`; and inside `execute_tool_script` a result's `.get()` raises `KeyError` for a missing key, so index it.
- The computer-use screenshot of this machine's editor came out washed out (an HDR desktop, maybe); `CaptureEditorImage` and `SlateInspectorToolset.Screenshot` give the true colors.
