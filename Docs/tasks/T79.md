- **The editor crashed when my script reloaded `L_Stage` from disk** (`EditorLoadingAndSavingUtils.load_map` on the open map, after `set_dirty_flag(False)` on its package). My person restarted it. `BP_Robot` had been saved before, so nothing was lost. The map had shown as unsaved since before this session, which is why I tried to reload it.
- After the restart, **Unreal MCP didn't come up**: the log said `HttpListener unable to bind to 127.0.0.1:8000`, because the crashed editor still held the port when the new one started. Typing `ModelContextProtocol.StartServer` into the editor's console box started it (`Created new HttpListener on 127.0.0.1:8000`), and the MCP client reconnected on the next call. Typing into the console box from the background did nothing; it needed full-screen control.
- The arm signs were found by posing the placed robots' `ArmPivotL` and `ArmPivotR` from editor Python (`set_relative_rotation`) and capturing the viewport. That did not mark the level as unsaved.
- In PIE, a Slate inspector `Click` on Test for Free only focused the button; `PressKey` Enter then pressed it.

### Unreal MCP and editor rules found in this task

- **Never reload the open map from disk in editor Python.** `load_map` on the current map crashed the editor. If an open level must lose unsaved changes, ask my person to reopen it, or re-place what you need and save.
- **After an editor crash, check the log for `HttpListener unable to bind`.** If it's there, run `ModelContextProtocol.StartServer` in the editor's console box.
- `ObjectTools.set_properties` takes `values` as a JSON string, and `get_properties` takes `instance` as `{"refPath": ...}`.
- `SubobjectDataSubsystem.attach_subobject(parent_handle, child_handle)` re-parents a Blueprint component; set its relative transform after the move.
