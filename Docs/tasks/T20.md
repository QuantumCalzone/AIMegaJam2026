### Unreal MCP rules found in this task

- **MCP can import sound files after all, through the editor's auto-import.** Copy the `.ogg`, `.wav` or `.mp3` into a folder under `Content/`, and the running editor makes a `SoundWave` named after the file within a second or two. First set `bPromptBeforeAutoImporting` to false on `/Script/UnrealEd.Default__EditorLoadingSavingSettings` (it is true here and would show a prompt), and `bAutoDeleteAssets` to false, so that deleting the copied source files afterwards keeps the assets. Both were set in memory only, for this editor session. It may work for fonts too (T14 found no import tool).
- **New asset types from engine copies:** `AssetTools.duplicate` of `/Engine/EngineSounds/Music` and `SFX` made the sound classes. Set `ParentClass` to null so they don't point back at the engine's `Master`.
- **`Audio|Components|Audio|FadeOut`, `FadeIn`, `AdjustVolume`, `Stop` and `SetVolumeMultiplier` each have two node types, and the DSL picks the Synth Component one**, so it can't wire them to an Audio Component ("Could not connect pin ... to self"). `Audio|Components|Audio|StopDelayed` has one type and works. A fade would need `create_node` with `declaring_class` `/Script/Engine.AudioComponent`.
- **An object literal works on an object pin:** `(Audio|PlaySound2D :Sound "/Game/NHOS/Audio/UI/S_Click.S_Click")`, and the same for `MakeSlateSound :ResourceObject`.
- **A new function's inputs exist for the DSL only after a compile.** Add the graph and its params, run `compile_blueprint`, then write the graphs that call it.
- **A component function named like one of its owner's functions** (`EndShow` on both `BP_Show` and the component) read back as `CallFunction|EndShow`, so it was renamed `EndCheer` to be sure.
- **`save_assets` with an empty list saves every dirty asset**, including `L_Stage` once a component is added to `BP_Show` (its placed instance changes). Lock the map first, or pass the paths.
- **`git pull` fails while the editor runs if an incoming `.uasset` is one the editor holds open** ("unable to unlink old ...: Invalid argument"; here `WBP_Unavailable`). HEAD stays put, but the pull's text files are left in the tree. Close the editor before you pull asset changes.
