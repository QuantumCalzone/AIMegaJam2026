### Unreal MCP and editor rules found in this task

- **A second editor runs at about 3 fps in the background,** because the editor throttles itself when it isn't the foreground window. `bThrottleCPUWhenNotForeground` isn't exposed to Python, and the console's `set` command is refused in the editor. Start the editor with `-ini:EditorSettings:[/Script/UnrealEd.EditorPerformanceSettings]:bThrottleCPUWhenNotForeground=False`: it applies to that process only and changes no file. The same switch sets the PIE window's size: `-ini:EditorPerProjectUserSettings:[/Script/UnrealEd.LevelEditorPlaySettings]:NewWindowWidth=1440`.
- **Console commands for the PIE world** (`stat unit`, `startfpschart`) typed into the editor's console box go to the editor viewport. From Python, `unreal.SystemLibrary.execute_console_command(world, cmd, player_controller)` with `UnrealEditorSubsystem.get_game_world()` reaches PIE.
- **`stat unit` draws under the role card in PIE.** `startfpschart` / `stopfpschart` print the average frame, GPU and game thread times to the log instead. To compare, hide and show the new actors inside one PIE session (`set_actor_hidden_in_game`), because other editors' load changes by the minute.
- **`EditorActorSubsystem.get_all_level_actors()` returns nothing useful while PIE runs.** Stop PIE before running a layout script.
- **The Slate inspector's refs change with each PIE window** (`w3`, `w4`, ...). Look them up by text from a fresh `Snapshot` before each click. The console box was `tb1` inside the `Cmd` menu every time; a `Type` into it returned false until a `Click` on it first.
- **Lighting channels keep a new light off the stage by construction:** a light on channel 1 only lights only parts on channel 1. `PrimitiveComponent.set_lighting_channels(False, True, False)` sets a part; a light takes `set_editor_property("lighting_channels", unreal.LightingChannels(channel0=False, channel1=True))`.
- **The save:** `EditorLoadingAndSavingUtils.get_dirty_content_packages()` and `get_dirty_map_packages()` listed only `L_Stage` before `LevelEditorSubsystem.save_current_level()`.
