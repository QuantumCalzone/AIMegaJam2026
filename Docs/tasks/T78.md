**Unreal MCP rules found in this part:**
- **`ObjectTools.set_properties` takes `values` as a JSON string,** not an object. An object returns false and sets nothing.
- **`BlueprintTools.find_nodes` needs `title`** (pass "" for every node), and `LogsToolset.GetLogEntries` needs `pattern` (pass "" for every line). `find_nodes` and `get_connected_subgraph` both return refs (`refPath`), so comparing the two lists finds cut-off nodes.
- **A function input shows as an output pin of its entry node** in the result of `add_function_param` (`EGPD_Output`), and an output as an input pin of the result node. That is expected, not a wrong direction.
- **The Cmd box takes a whole `py ...` line through `Type` with `submit`.** `FillForm` on it returned false. `py exec(open(r"<file>").read()); face("<step>")` runs a script file, so a long script never goes through the textbox.
- **Editor Python reads Blueprint variables that aren't Instance Editable** with `get_editor_property` (`Stage`, `ActionBuilder`, `ChipsWrap`, `FaceLive`), and `call_method` calls a live widget's Blueprint functions and returns their outputs.
- **`SlateInspectorToolset.Screenshot` returns `{"returnValue": {"mimeType": "image/png", "data": <base64>}}`.**

**Unreal MCP rules found in this part:**
- **`Tools/dslpp.py` doesn't take a dotted graph name** in its `;;; GRAPH` header: `;;; GRAPH EventGraph.Face` gave an empty file and wrote nothing (with no error). Expand an `EventGraph.<part>.txt` file under `;;; GRAPH EventGraph`.
- **`UMGToolSet.AddWidget` takes the blueprint as `/Game/.../WBP_Stage.WBP_Stage`** (with the object name); the bare package path is refused. `childIndex` 1 puts the widget second.
- **`ObjectTools.get_properties` takes `instance`, not `object`;** the toolset's full name is `editor_toolset.toolsets.object.ObjectTools`.
- **From Git Bash, `cmd //c auto.bat` failed** ("not recognized") in this session, from the repo folder and from the script's folder. PowerShell's `Start-Process` with the editor and its arguments started the game window.
- **The Slate inspector's `Type` writes into a disabled text box,** so a driver must check that the field is enabled before it types.
