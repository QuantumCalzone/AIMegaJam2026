### Editor scripting found in this task

- **A Slate tick script must wait on game time, not ticks.** With the editor in the background its frame rate drops, so a 60-tick wait outlasted the 2.8 s cheer and the "cheer" frames showed the robots at rest. Waiting until a robot's `Clock` has advanced by N seconds fixed it. `bThrottleCPUWhenNotForeground` is set through `unreal.find_object(None, '/Script/UnrealEd.Default__EditorPerformanceSettings')`; `unreal.EditorPerformanceSettings` doesn't exist in Python.
- **`BP_Robot`'s timers (`TalkUntil`, `CheerUntil`) can't be set from Python on a live instance** ("cannot be edited on instances"). Call the functions instead: `SetLit(True)` starts talking, `Cheer()` cheers, `SetCut("CUT")` cuts (its argument is the label's stamp, a string), `Rise()` stands it up.
- **A live component's transform can be set from Python in Simulate** (`set_relative_location`, `set_relative_location_and_rotation`), so a "before" can be shot without touching the asset.
- **A component template's transform** is set through `SubobjectDataSubsystem.k2_gather_subobject_data_for_blueprint` and `SubobjectDataBlueprintFunctionLibrary.get_object`, then `set_editor_property('relative_location' / 'relative_rotation' / 'relative_scale3d')`. A new component: `add_new_subobject(AddNewSubobjectParams(parent_handle=..., new_class=unreal.SceneComponent, blueprint_context=bp))`, then `rename_subobject`.
- **Python has no PIL here.** A small Swift tool tiled the sheets (`Saved/T109/bin/grid.swift`).
