## Findings

### T28: Scene Prep pause and the split card (2026-11-15, built; waits for my playtest)

Built on the Windows PC through Unreal MCP, checked in a game window (free autoplay) and in PIE (a 1600 × 900 floating window, Test for Free, clicked through with the Slate inspector).

- **The pause:** `ScenePrep` no longer calls `StartScene`. Its last node now calls a new function, `OpenPrep`, which puts the card in prep mode, prints `NHOS: PREP shown scene=<n>`, loads the switches and, with autoplay on, calls `StartFromPrep` at once. `StartFromPrep` runs only while the phase is `scene prep` (so a second click does nothing), puts the card in scene mode, prints `NHOS: PREP start scene=<n>` and calls `StartScene`. `StartScene` itself is unchanged. Its only caller was `ScenePrep`.
  - `ScenePrep` and `UpdatePrompt` have no sources in `Graphs/`, and their read-backs are lossy (`UpdatePrompt` reads back its `SetPrompt` call as `Class|AssetExportTask|SetPrompt`). So both were changed by node edits, not rewritten: in `ScenePrep` the `StartScene` call node was deleted and a `CallFunction|OpenPrep` node wired after the `SETUP` print; in `UpdatePrompt` a `CallFunction|PrepPrompt` node now sits between `ComputePrompt` and `SetPrompt`.
  - `PrepPrompt` (new) sets the prompt for the `scene prep` phase, which `ComputePrompt` has no branch for: "Read the card on the right: ... Press Start the scene when you are ready.", with the hint "Read your card first." The input box stays disabled during prep.
- **`WBP_Stage`:**
  - The card's scene, cast and stage parts (`SceneTitle`, `SceneText`, `CastTitle`, `CastBox`, `SetTitle`, `PlacesText`, `PropsText`) now sit in a new VerticalBox, `PrepBox`. My card (`YouAre`, `MeText`, `RoleText`, `WantText`, `NoteFrame`) stays outside it, so it shows in every phase.
  - New `StartButton` in the input row, after `ContinueButton`, with the same style (gold, dark 20 pt label "START THE SCENE", 10 px left padding). Its click calls `BP_Show.StartFromPrep`, the same way See the results calls `RevealEnd`.
  - New function `SetPrepMode(Prep)`: in prep, `PrepBox` and `StartButton` show and Send and Pass collapse; in the scene, the reverse.
  - `InfoSize`'s maximum height went from 640 to 1032 (the full 1080 height less T27's 24 px margins), so Scene Prep shows nearly the whole card. In the scene the card holds only my part (about 300 px), so the larger limit changes nothing there. The panel stays right of the robot at Right.

- **Unreal MCP rules found in this task:**
  - **`AssetTools.read_file` reads only under `Content/` and `Saved/`,** so a script can't read `Graphs/` sources directly. Copy them to `Saved/Txx/src/` first.
  - **`find_nodes` matches the node's title without spaces** for function calls: `StartScene` finds the call, `Start Scene` finds nothing.
  - **`UMGToolSet.WrapWidgets` drops the wrapped children's slot padding** and gives the first child's padding to the new wrapper's slot. Read the paddings first and set them back.
  - **To make a new button's click event,** call `UMGToolSet.BindToEventProperty` (`eventName` `OnClicked`, `propertyName` the button, `propertyClass` `/Script/UMG.Button`), then write `(event OnClicked(<Button>) ...)` to the EventGraph alone.
  - **To replace one call node without rewriting a graph,** `delete_node`, then `create_node` `CallFunction|<Name>` and `connect_pins` from the previous node's `then` (index 0). To insert a call, `break_pins` the old exec link first.
