- **Unreal MCP rules found in this task:**
  - **No MCP tool reloads an asset from disk** (no reload, revert or console command in `AssetTools`, `EditorAppToolset` or `BlueprintTools`). To learn what an interrupted session left in an open asset, check `AssetTools.is_dirty`, then read that session's transcript (`export_transcript`) for its MCP calls.
  - **`create_node` takes `Variables|Default|SetX` and `Variables|Default|GetX`** for a Blueprint's own variables. A setter's pins are `execute` 0 and `<Var>` 1 in, `then` 0 and `Output_Get` 1 out.
  - **A pin for `connect_pins`, `break_pins` and `set_pin_value`** is `{direction: EGPD_Input or EGPD_Output, index_id, node: {refPath}}`, with `index_id` counted per direction, as `get_node_infos` reports it. `remove_variable` and `compile_blueprint` return null on success; read the editor log for the compile.
  - **A tool error inside `execute_tool_script` fails the whole call** with the tool's error text, even when the script catches it. Ask only for nodes that exist.
  - **To drive a game window's title screen without a mouse,** `WScript.Shell.AppActivate(<pid>)`, then `SendKeys("{TAB}")` and `SendKeys("{ENTER}")`, work from PowerShell; Tab moves from Play via Relay to Test for Free.
