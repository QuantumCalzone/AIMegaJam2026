Back to [the plan](../Plan.md). This task's title line, **Model and effort**, **Depends on**, **Needs**, **Touches** and any **Waiting:** or **Blocked:** line are in its entry there, under "Open".

## Task

- **Why:** the last step of my web go (T112's verdict): the game plays in the browser on its itch.io page. itch.io takes browser games up to 500 MB in all and 200 MB per file, and today's Windows content is one 414 MiB `.ucas`.
- **Steps:**
  1. **Read first.** T123's findings (the packaging command, the build's files, the hosting it needs) and its choice of 5.9 or a web copy; `Docs/Builds.md` and "Deploys to itch.io" there; T112's web table in `Docs/Mobile/README.md`.
  2. **Package** a Shipping web build as T123 found, with T125's texture cap, T126's lighter meshes and T127's files. Split the content so no file is over 200 MB and the whole build is under 500 MB (chunks, compression, smaller music if needed).
  3. **Check it for secrets** with `Tools/check_build_secrets.py` (teach it the web build's files if it needs to), and set analytics as `Docs/Builds.md` says before any test.
  4. **The deploy tool.** Add a web channel to `Tools/deploy_itch.py` (and the editor's Tools > itch.io menu) that packages and pushes the web build with butler, beside the Windows and Mac files and never in place of them, and never touching the jam's file.
  5. **The page.** After my OK, upload it as the page's playable HTML file: the embed size, the fullscreen button, and "SharedArrayBuffer support" if the build needs cross-origin isolation (T123). Put the settings in `Docs/ItchPage.md`.
  6. **Check it** on the itch.io page in Chrome: a free show and a Play show to the end screen; note the load time and the download.
- **Done when:** the web build plays both shows on the itch.io page in Chrome; every file is under 200 MB and the build under 500 MB; the secrets check passes; `Docs/Builds.md` and `Docs/ItchPage.md` say how to build and ship it.
