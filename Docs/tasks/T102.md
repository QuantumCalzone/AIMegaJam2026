## Findings

### The build (2026-11-19, this Mac, by the sheet's part 0 order)

- **Imports in place:** an editor Python script run from the Cmd box (`py "<file>" <job>`, typed through the Slate inspector into the status bar's Cmd textbox) with `AssetTools.import_asset_tasks` and `AssetImportTask(replace_existing=True, automated=True, save=False)`. **The importer takes FLAC**: no WAVs were needed. Every length matched part 2a's table within 0.1 s; every loop is 2 channels, `Looping` on, `SC_Music`. T101's 16 sounds and the 31 OpenAI, SpaceXAI and Meta syllables came in the same way, with part 2b's settings. The Anthropic and Me syllables kept their files; only their Volume changed (0.6 to 1.0). 85 assets, saved by explicit path. `find_package_referencers` on the replaced loops still lists `BPC_ShowAudio`.
- **The MCP has no tool that runs editor Python or imports over an asset.** `ProgrammaticToolset` allows only json, math, re and a few others, so the Cmd box is the way (T46, T105).
- **The recorder needs no splice.** The DSL writes `Audio|Recording|StartRecordingOutput`, `Audio|Recording|FinishRecordingOutput` (`:ExportType "WavFile"`) and `Utilities|HasLaunchOption` directly (`find_node_types` lists them), so `RecPhase` and `RecStop` are plain sources in `Graphs/`.
- **A new variable's default doesn't reach a component that a Blueprint already holds.** `RecMax` (60) and `ReactDelay` (3) were set on `BPC_ShowAudio`'s class defaults after the first compile, but `BP_Show`'s `Audio` component had been re-made with 0 for both, and the first game window read 0 (`SetTimer passed a negative or zero time`; the Reactions loop came in 0.3 s after the stinger). Fixing it would have meant another change to `BP_Show`, so the two variables are gone: `PlayPhase` waits a literal **3.0** s and `RecPhase` records up to a literal **60.0** s. Each is still one number to tune. `RevealAt`, `RecN`, `RecName` and `RecLive` start at the type's own default, which is what they need.
- **`write_graph_dsl` leaves the old nodes behind** (T50, T71), and those keep their references: `Sfx`'s two old "blip" branches still pointed at `S_TalkBlip` after the rewrite. They were deleted by hand (`find_nodes` + `delete_node`); then `S_TalkBlip` had no referencer and was deleted.
- **`BP_Show.OpenPrep`:** the one pin (`break_pins` from `Get CardId`, `set_pin_value` "scene_prep", delete the loose getter). Nothing else in `BP_Show` changed. Both Blueprints compile with warnings as errors.
- **zsh doesn't split an unquoted variable:** `git lfs lock $files` made one lock on a path with newlines in it. It was removed by id; lock files one by one.
