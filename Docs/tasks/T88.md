### Which kinds look too easy or too hard

From the screenshots, the 120 texts and the relay show:

- **Too easy:** `key_blank` gives the whole rule away but one word, and the word is often guessable from the rest ("Start every turn by ███████ at another actor."). `autocorrect` reads as the note with typos ("Mention your favorite prom every thyme you speak."), so it is nearly the note itself. `opposite` is the note reversed, which a player undoes in one step, and the bots notice when a player matches it "too neatly" (they did in show 2).
- **Misleading:** `opposite` for `throw_once` ("Opposite of: Never throw anything at the actor you trust most.") reverses both "never" and "least", so undoing it gives "throw at the actor you trust most". The real note says least. I threw at the actor I trusted most, and the bots called it "matching the note's opposite clue". It worked as play but taught the wrong target, so on my person's call it now reads "Never throw anything at the actor you trust least."
- **About right:** `vowels`, `consonants`, `first_letters` and `pig_latin` take a moment to decode but get there; `key_only` gives one word, which with the category's kind of action is a fair hint ("Center", "hold").
- **Hard:** `riddle` ("A rolling robot gathers no suspicion.") and `emoji` (💬💖🎩 needed guessing; 🗿 for "stay at Center" is a stretch) are the hardest. `scrambled` on a long note (`hold_prop`, 19 words) is slow to read inside a 30-second turn. These are fair for scenes 3 and 4, where a player has watched the bots for a scene or two, but they can fall in scene 2.

### Unreal MCP rules found in this task

- **The editor's auto-import makes font faces too:** copy a `.ttf` into a `Content/` folder (with `bPromptBeforeAutoImporting` false), and `FontFileImportFactory` makes a `FontFace`. It then asks with a modal "Font Face Import Options" dialog ("Would you like to create a new Font asset ...? Yes / No / Cancel"), which blocks the game thread and every MCP call. The dialog is Slate, so no Windows button can be clicked: an `EnumWindows` list finds it by title, `PrintWindow` captures it, and `SetForegroundWindow` plus an Enter key press picks its default (Yes). Yes makes `<Face>_Font`; `AssetTools.move` renames it. Set `bAutoDeleteAssets` false first, or deleting the copied `.ttf` deletes the new assets. Both settings reset when the editor restarts.
- **A restarted editor can stop at "Restore Packages"** (the autosaves of unsaved work) before the MCP server starts; port 8000 stays closed until it is answered. A `WM_CLOSE` to that window skips the restore.
- **`AddWidget` + `ToggleWidgetAsVariable` + `set_properties`** with `font` as `{"fontObject": ..., "typefaceFontName": ..., "size": ...}` and `colorAndOpacity` as `{"specifiedColor": ..., "colorUseRule": "UseColor_Specified"}` builds a styled text block with no editor click.
- **A node edit in a graph with no `Graphs/` file** (`ScenePrep`, `ShowPrep`): `find_nodes` with `title: ""` lists every node, `get_node_infos` gives pins and links, then `break_pins`, `create_node` (type ids from `find_node_types`, which needs `context_pins: []`), `connect_pins`, `set_pin_value`, and `add_node_pin` on a string `Append` for more inputs.
