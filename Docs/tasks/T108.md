## Findings

- **Meta's body is a texture, not the seat color.** T83's Hyper3D body (`T_MetaBody_BaseColor`, a royal-blue tee) and arms sit on `MI_MetaBody`/`MI_MetaArm` with `TintAmount` 0, so the seat color that `ResetLook` sets on the `seat` parts doesn't show on them. My person chose to leave the body to T103, which replaces this model with the approved black and mustard top: **T103 should match that top's mustard to #C8AC12**, in its texture, or as a neutral texture on a `seat` part with `TintAmount` 1.
- **The old blue is still stored, unseen, in** `MI_MetaBody`, `MI_MetaArm` and `MI_MetaHead` (their `Color` parameter, ignored at `TintAmount` 0) and in `L_Stage.umap` (the placed robots' values, which `SetPersona` and `ResetLook` overwrite at run time). Neither changes what the game shows, so I left them: the Meta materials are T103's, and `L_Stage` isn't worth a binary change for nothing.
- **`BP_Robot.SetPersona` holds ten copies of the five seat colors.** Earlier `write_graph_dsl` runs left disconnected islands of `Make Linear Color` and `Select` nodes in the graph. I set all ten of Meta's copies with `set_pin_value`, so the live one is surely the new mustard; the islands don't run. A future rewrite of the graph from its `Graphs/` file would clear them.
- **`set_pin_value` doesn't mark the Blueprint changed,** so `save_assets` says "All files are already saved" and writes nothing. Reading one graph with `read_graph_dsl` marks it changed (T47's finding); then `save_assets` writes it. Check the file's date after a save.
- **`screencapture` can't capture a game window from this session's shell on this Mac** ("could not create image from window"), which T27 used. `SlateInspectorToolset.Screenshot` of the PIE window, returned as base64 from `execute_tool_script`, works.
- **Mustard and gold.** #C8AC12 sits at hue 51°, against 42° for the UI's gold (#F2C14E) and 24° for Anthropic's orange, and measures 8.2:1 on the ink panel. In the PIE shots it reads clearly apart from the gold Action! button and the header. The director's note card (a dimmed gold) is the nearest color on screen, but it is a panel, never a name or a bar. The audience's mustard (#C9A43F) is close in lightness but much duller, and stays in the stalls.
- **Not checked by eye:** Meta's ballot ticket, name tag and speech bubble went by too fast in autoplay for a screenshot; they call the same `UIStyle.SeatColor` that colors the chat line, which shows the mustard.
