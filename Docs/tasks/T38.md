**`WBP_SpeechBubble`** (`/Game/NHOS/UI/WBP_SpeechBubble`, parent `UserWidget`). The tree (every widget is a variable):

```
Root            Overlay, HitTestInvisible. Its geometry is the layout rect; it never moves.
└ BubbleBox     Overlay, Collapsed until a line shows. Place moves it (render translation); the fade sets its opacity.
  ├ TailDown    SizeBox 18 × 18, slot centered at the bottom with 4 bottom padding, render angle 45°.
  │ └ TailDownFill  Border, a seat-color rounded box (SetEdge).
  ├ TailUp      SizeBox 18 × 18, slot centered at the top with 4 top padding, render angle 45°, Collapsed.
  │ └ TailUpFill    Border, as TailDownFill.
  └ Edge        Border, slot padding 13 top and bottom (half of each tail's diamond sticks out).
    │           Brush: UIStyle.Brush(InkSolid, seat color, CardTrim 3, PanelRadius 16). Padding S4 × S3 (16 × 12).
    └ TextBox   VerticalBox
      ├ LeadText    TextBlock, the action style, slot bottom padding 4. Collapsed unless a lead shows.
      └ TextStack   Overlay
        ├ SpeechText  TextBlock, UIFont("Speech") 20 in UIColor("Text") white, WrapTextAt 500.
        ├ SpeechShown TextBlock, the same: the typed part, on top of SpeechText while it types.
        ├ ActionText  TextBlock, UIFont("Action") 18 italic in UIColor("Quiet"), WrapTextAt 500.
        └ DotsBox     SizeBox, width 64, Collapsed.
          └ DotsText  TextBlock, UIFont("Header") 32 bold white, centered.
```

The fill is `InkSolid`, not the panels' 92% `Ink`, so the tail's hidden half never shows through. Variables: `Shown`, `Fading`, `Alpha`, `TypingOn`, `Dot`, `LastUp`, `FullSpeech`, `FadeStepTime`, `DotTime`, `WrapAt`, `Margin`, `Gap`, `TailInset`, `FX`, `FY`, `MvX`, `MvY`, `MvD`, `ViewTL`, `ViewBR`, `KTL` and `KBR` (Vector2D arrays), `KeepView` and `NullWidget` (Widget), `KeepPanels` (Widget array). All functions are impure (made with `add_function_graph`). Their sources are in `Graphs/WBP_SpeechBubble/`.

| Function | Inputs | Outputs | What it does | Caller |
|---|---|---|---|---|
| `ShowLine` | `Name` (String), `Color` (LinearColor), `Action` (String), `Speech` (String), `Lead` (String) | none | Shows a line whole, at once: its speech; with no speech, its action in the action style; `...` if both are empty. `Lead` shows above the speech (pass `""` for none). Stops a fade or the dots. | `BP_Robot.Say` |
| `TypeBegin` | `Speech` (String) | none | Starts the typing: the whole speech invisible underneath and the typed part on top, so the bubble keeps its final size. | `BPC_LinePlayer.StartType` |
| `TypeTo` | `N` (Integer) | none | Shows the first N letters. | `BPC_LinePlayer.TypeStep` |
| `TypeEnd` | none | none | Shows the whole speech. | `BPC_LinePlayer.EndType`, `ShowLine`, `ShowTyping` |

**The fit rule** (`Fit`, in viewport units):
1. Stay inside the window's `Margin` (`UISize("Edge")`, 24).
2. For each visible panel in `SetKeepOut`'s order, grown by `Gap` (`UISize("S2")`, 8): if the bubble overlaps it, take the shortest of the four moves (left, right, down, up) that clears it and stays inside the margin. If none fits, stay.
3. The tail points at the anchor, kept `TailInset` (`PanelRadius + S3`, 28) from the corners. `Up` is true when the bubble ended up entirely under its anchor.

The sheet's rule took only left, right or down, in that order. The shortest of four moves keeps the bubble nearest its speaker.

**Where the build differs from the sheet:**
- **`Place` measures with `LocaltoViewport`, not `LocaltoAbsolute`.** In this editor `UserInterface|Geometry|LocaltoAbsolute(Vector)` returned (0, 0) for every widget's geometry, `MyGeometry` included, while `GetLocalSize`, `GetAbsoluteSize` and `UserInterface|Geometry|LocaltoViewport` were right (a debug print showed the bubble at viewport (369, 142) with `LocaltoAbsolute` 0). So the bubble, the window and the panels are all measured in viewport units: `LocaltoViewport`'s second output, `ViewportPosition`, the DPI-scaled units `WBP_Stage` is laid out in (1916 × 1080 at 1600 × 900), where `ProjectWorldLocationtoWidgetPosition` lands too. The sheet's `WBP_Stage.KeepOut` and `ToLocal` aren't needed: `SetKeepOut(View, Panels)` takes the widgets, and the bubble measures them itself each frame.
- **`EventConstruct` hides only when no line shows.** A host may call `ShowLine` before the widget is constructed (a `WidgetComponent` builds its widget later than `SetWidget`), and an unconditional `HideNow` at construct would wipe that line.
- **No `FindStage`, no `SetRobot` and no projection in the bubble.** The host places the bubble (a screen-space `WidgetComponent` with pivot (0.5, 1), or a canvas slot with alignment (0.5, 1)), and the bubble only fits itself around that spot. The same `Place` serves both modes.
- **The typing dots use the 32 pt display type** (`UIFont("Header")`): at 20 pt bold they read as specks in the shot.
- **Text:** `ShowLine`'s `Speech` should be the text the chat line shows (after `WBP_Stage.CleanText`), and `TypeBegin` gets the same text, so `TypeTo`'s N counts the same letters.

**Unreal MCP and editor rules found here:**
- `ObjectTools.set_properties` takes `values` as a JSON string, not an object (an object returns false and sets nothing).
- On this server, `call_tool` takes `toolset_name` and `tool_name` separately (`editor_toolset.toolsets.blueprint.BlueprintTools` and `write_graph_dsl`), not one dotted name.
- `get_node_type_pins` leaves a node in the graph you pass. Write that graph again afterwards, or probe in a throwaway graph.
- In editor Python, `UWidgetBlueprintLibrary` is `unreal.WidgetLibrary` and `USlateBlueprintLibrary` is `unreal.SlateLibrary`, and there is no `create` (the Create Widget node is internal). Make widgets through a Blueprint function with `UserInterface|CreateWidget :Class ... :OwningPlayer PC`, which also works on a class default object.
- In editor Python, `UserWidget.get_widget_from_name` and the `WidgetTree` can't be reached. To find a panel that isn't a variable, walk up from a widget variable with `get_parent()`. In `WBP_Stage`, `HeaderSize`, `InfoSize` and `LowerSize` aren't variables; `TurnText`, `PrepBox`, `InputBox`, `ClapperBox`, `EventBanner` and `StampText` are.
- A viewport widget with only `set_position_in_viewport` fills the window: give it `set_desired_size_in_viewport` too.
- `SlateInspectorToolset.Windows` `select` on the PIE window maximized it once. `Click` on its "Restore Down" button put it back to 1600 × 900.
- `UserInterface|Geometry|LocaltoAbsolute(Vector)` returned (0, 0) here. Use `LocaltoViewport` (see above).

**Unreal MCP rules found here:**
- From Git Bash, a JSON argument that starts with `/Game/...` is rewritten to `C:/Program Files/Git/Game/...` ("is not valid EdGraph"). Set `MSYS_NO_PATHCONV=1` for those calls.
- `Game|AddComponentbyClass` in an actor shows only `self` and `Class` (no `bManualAttachment`). The component attaches to the root, and `Transformation|AttachComponentToComponent` (snap to target) moves it. The return value takes the class's type, so it sets a `WidgetComponent` variable directly.
- `WidgetComponent.Widget` can't be read with `ObjectTools.get_properties`. Read the robot's own `BubbleW` variable instead.
- `ObjectTools.get_properties` on a widget's `Slot` gives a path like `...WidgetTree.HeaderBox.VerticalBoxSlot_1`, and the part before the slot is the parent panel. A slot's `Parent` property can't be read.
- An editor in the background runs at about 3 frames a second, which slows every frame-counted timer in PIE. `ObjectTools.set_properties` on `/Script/UnrealEd.Default__EditorPerformanceSettings` with `{"bThrottleCPUWhenNotForeground": false}` turns that off for the session; set it back before closing.
