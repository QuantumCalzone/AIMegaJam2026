- **The banner (`WBP_Stage`):**
  - Widgets: `BannerSize` (SizeBox, width 560, `SelfHitTestInvisible`) in `StageArea`, left-aligned at 900 and 24 from the top, so it sits in the open strip between the header (right edge 884) and the card (left edge 1476), clear of the robots' name labels.   - Functions, sources in `Graphs/WBP_Stage/`: `ShowBanner(Line)` adds the line to `BannerQueue`, prints `NHOS: BANNER <line>` and starts `NextBanner` if no banner is up. `NextBanner` shows the next line at full opacity and sets a 3.5 s timer to `FadeBanner`, which lowers the opacity by 0.1 every 0.05 s (0.5 s) and then calls `NextBanner`. So each banner holds about 4 s, one at a time, in order. `BannerAlpha` is a variable, because a pure `GetRenderOpacity` read would run again at each use.

- **Unreal MCP rules found in this task:**
  - **`ObjectTools.get_properties` takes `instance` and `properties`; `set_properties` takes `instance` and `values`, a JSON string** of property names to values (for example `{"Padding":{"left":0,"top":24,"right":0,"bottom":0}}`).
  - **`AssetTools.save_assets` (plural) takes package paths** (`/Game/NHOS/UI/WBP_Stage`). There is no `save_asset`.
  - **To keep a Slate screenshot,** write its base64 `data` with `AssetTools.write_file` to an absolute path under `Saved/` with a `.txt` extension (only `.csv .html .json .md .py .txt` are allowed), then `base64 -d` it to a `.png`.
  - **To call another Blueprint's function with `create_node`,** use `Class|<Blueprint name without underscores>|<Function>` (`Class|WBPStage|ShowBanner`). `find_node_types` needs `context_pins: []`.
  - **To swap a call node without reading its graph:** read its pins with `get_node_infos` (exec in, `then`, `self`, the data input), `delete_node`, `create_node` at the same position, and `connect_pins` each saved pin to the new node's pin of the same name. `get_node_infos` gives a call node's type as `|AddLogLine`, with no class, which is enough to check what you delete.
  - **A UMG `OverlaySlot` defaults to `HAlign_Left` and `VAlign_Top`.** A centered slot with large left and right padding put the banner about 260 units right of where I expected, and I found no reason. A fixed-width `SizeBox`, left-aligned with a left padding, lands where you put it.
  - **`execute_tool_script`'s `run()` must return a dict with string keys.** An int key fails the call, but only after the edits in it are made.
