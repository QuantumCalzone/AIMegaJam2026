# T124 The web, part 2: the relay answers the web build (CORS)

Back to [the plan](../Plan.md). This task's title line, **Model and effort**, **Depends on**, **Needs**, **Touches** and any **Waiting:** or **Blocked:** line are in its entry there, under "Open".

## Task

- **Why:** T112 found it: a web build calls the relay from a browser page, so every call is a cross-origin request. The relay sends no CORS headers today and has no `OPTIONS` route (`Relay/src/index.js`: `POST /`, `GET /health`, `POST /event`, `GET /stats`), so the browser blocks the answers. The desktop game sends no `Origin` and must keep working as it does.
- **Steps:**
  1. **Read first.** T123's findings (the origin itch.io serves the web build from, the headers the build sends, and whether the page is cross-origin isolated), `Relay/README.md` and T67's file (the routes and their limits).
  2. **Allowed origins.** A Worker variable, `WEB_ORIGINS`: the web build's origins, separated by commas (itch.io's HTML5 player origin, and `http://localhost:<port>` only in `wrangler dev`).
  3. **Preflight and headers.** For `/`, `/health` and `/event` only: answer `OPTIONS` from an allowed origin with `Access-Control-Allow-Origin` (that origin, never `*`), `Access-Control-Allow-Methods`, `Access-Control-Allow-Headers: content-type`, a `Access-Control-Max-Age`, and `Vary: Origin`. Add `Access-Control-Allow-Origin` and `Vary: Origin` to every answer for an allowed origin, errors included, so the game can read the relay's error bodies. `/stats` and `/dashboard` (T117) stay closed to other origins. The per-IP limits and the budget stay as they are.
  4. **Tests.** In `Relay/test/curl-tests.sh`: a preflight from an allowed origin gets the headers; one from another origin gets none; a `POST /` and a `POST /event` from an allowed origin carry the header; a request with no `Origin` (the desktop game) answers as before.
  5. **Deploy** after my OK, as "Deploy" in `Relay/README.md` says, and check that the desktop game's Play still works.
- **Done when:** the tests pass on `wrangler dev` and on the deployed relay; a web build in Chrome (T123's copy, or a page that makes the same calls) reads `/health`; a desktop show in Play still works; `Relay/README.md` documents `WEB_ORIGINS`.
