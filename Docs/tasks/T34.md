### Unreal MCP and Slate rules found in this task

- **Slate draws a rounded box's outline at full strength whatever the widget's render opacity.** The title and end screens hide the stage by render opacity 0, and every `UIStyle` panel trim and the input box's edge showed through. `HideCheck` hides `RootBox` while the opacity is under 0.5. The same rule shaped the fading banner (no trim), the stamp (inked edges as nested fills, since `EventTick` fades it by opacity and never collapses it) and the tags (Hidden, not opacity 0, under a bubble).
- **`write_graph_dsl` on an existing function leaves the old graph's nodes in it, cut off from the entry.** Every rewritten function held a stale copy (`SetPrompt` held 505 nodes from earlier tasks). A reachability sweep from `K2Node_FunctionEntry` (exec outputs, data inputs; keep `FunctionResult` and comments) deleted them in every `WBP_Stage` function and in `HandleSend`, `LastWordPrompt`, `PrepPrompt`; both Blueprints compile with warnings as errors. Run it after each rewrite.
- **A bound pure node is read again where it's used.** `NextBanner`'s bound `Get(BannerQueue, 0)` was read after `RemoveIndex` and logged "Attempted to access index 0" (and lost the word count). Store such values in variables (`BannerNow`, `BannerWords`, `BannerHoldT`).
- **`UIStyle`'s impure calls nested in another call's argument are pruned** ("SeatColor was pruned because its Exec pin is not connected"): bind them first. A nested `UIColor` inside a `bind`ed `MakeSlateColor` is fine.
- **The DSL takes a newline inside a string literal** (it reaches the pin as character 10). It has no escape syntax; `(.r color)` is not a component (only x, y, z, rotator and transform parts).
- `Utilities|String|Split` binds as `(left right ok)`. `StringToInteger` takes `:InString`; Min, Max and Clamp are `Math|Integer|Min(Integer)`, `Math|Float|Clamp(Float)`. `find_node_types` needs `context_pins: []`; `set_properties` takes `values` as a JSON string. `AssetTools.read_file` lets a script write a DSL file without its text passing through the tool call (T33's note; the expanded files went to `Saved/T34/expanded/`).
- **On this Mac a Slate `Click` on a title button works after a `Hover` on it**; `PressKey` and `Type` go to the focused widget. When the main editor window comes to the front (a full-editor `Screenshot` with an empty ref does that), the PIE window loses the keyboard focus. Screenshot the PIE window by its ref (`Snapshot` depth 1). Once, the PIE window reopened maximized (1728 × 978 points); setting `newWindowPosition` again brought back 800 × 484.
