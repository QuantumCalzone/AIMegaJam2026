### Where the build differs from the sheet

The sheet's 15 "Decisions made for my person" were built as written, except where the items below change them (decision 2's plain white name, and "rises where it fell").


1. **`WinLine` is `RevealLine`.** `BP_Show` already has a String variable `WinLine` (T54's win banner text), so `add_function_graph` made `WinLine_0`. The sheet's survey of free names looked only at `Graphs/` files, not at the variables. The function is `RevealLine`; everything else is as the sheet wrote it.
2. **The entry's `when` comes from a JSON template** (`{"when": "show over, the reveal"}`), not a `Set Field` with a literal, because a literal can't go into `Set Field`'s wildcard value pin (T01). The other fields are typed node outputs, so they use `Set Field` as written.
3. **The reveal ask's state has no options.** `AskClosing` clears `AskOpts` right after it builds its state, so `AskWinReact`'s `ActorState` sends an empty `options`. The ask doesn't use them. The checker's sample case still passes the closing's options; that only changes what the paid run's sample state shows.

4. **T77's `StageLine` never reached the stage director, and T87 fixes it (my person's OK, 2026-11-17).** In the live graph, the director call sat in the `else` path of the seat-range check: the `if` body ended in a `Utilities|IsValid` branch (the face), and the DSL made everything after that `if` its else path. A seat is always in range, so from T77 (`dbe656f`) to T87 no line's action played at all: no move, look, grab, throw or give, though each face did. T93's game log has no play-time `NHOS: ACT` line; T65's has many. The face part is now its own function, `BP_Show.EmoteSeat(Seat, Id)`, and `StageLine` calls it, then the director, as T77 meant. The same trap was in this task's own `BPC_WinReveal.RiseAll` (its `WIN REVEAL` line never printed in the first show), so that print now comes before the `Unmask` block. A scan of every `Graphs/` source for an `if` whose body ends in an `IsValid` branch with code after it found no other.
