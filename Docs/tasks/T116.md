## Task

- **Why:** my question on 2026-11-19: I want a dashboard of the play stats that shows the prod game only, and never my own plays (T117 is the dashboard). The editor already sends nothing (T68), and test events are already left out (T67). But a packaged build keeps its player id and its Play stats toggle in a SaveGame inside its own folder: `<build>/AIMegaJam2026/Saved/SaveGames/player.sav`, because `Tools/deploy_itch.py` packages Development builds. (This PC's copy is in `Packaged/Windows/AIMegaJam2026/Saved/SaveGames/`.) A build's `Local/switches.json` is in that folder too. So each release I download or unzip starts with a new player id and Play stats on. `ignore_players` (T67) can't catch that id, and I would have to turn the toggle off or write a switches file for every new build.
- **What changes:** each of my machines gets one marker file, outside every build folder. Every build reads it at launch. When the marker says `test`, every event from that machine goes out as a test event. When it says `off`, the machine sends nothing. This holds for any build, whatever its own folder holds. I write the marker once on each machine.
