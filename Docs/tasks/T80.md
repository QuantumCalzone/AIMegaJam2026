### Unreal MCP and editor rules found in this task

- **A capture right after a script changes or attaches to a placed actor can miss it.** After `hats.py` attached a headpiece (and after calling `SetCut`), the first `CaptureViewport` showed Meta missing and my box without its face, though nothing was wrong; a capture in the next MCP call was right. Two captures inside one `execute_tool_script` were not enough. Capture again in a separate call before you judge.
- `BlueprintTools.add_variable` takes `type_name` `LinearColor` for a color variable; `ObjectTools.set_properties` on the Blueprint sets its default, with a color as `{"R": .., "G": .., "B": .., "A": ..}`, after a compile.
- `BlueprintTools.find_nodes` returns only node refPaths; `get_node_infos` with `nodes` gives each node's `type_id` (a variable getter's is `|Get<Name>`).
- A placed robot's `HeadSocket` can be moved from editor Python (`set_relative_location`, `set_relative_scale3d`) to try a fit; set it again after attaching anything to the robot, because the attach re-runs the construction script, which resets it from `SetPersona`.
