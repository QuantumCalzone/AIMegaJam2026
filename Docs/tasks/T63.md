### Unreal MCP rules found in this task

- **`write_graph_dsl`'s leftover chains can hold call nodes that break a compile.** `HandleSend` held three old copies of its whole graph, each with its own `SendHumanTurn` call, cut off from the entry. After `SendHumanTurn` gained parameters, every one of those stale calls failed the compile ("Could not find a pin for the parameter Verb of SendHumanTurn"), though none could ever run. `find_nodes` lists the live and the dead nodes alike, and `get_node_infos` can't tell them apart: trace from the function entry (`K2Node_FunctionEntry_0`'s `then`, then each `IfThenElse`'s `else`) to find the live one, and delete the stale ones before compiling. Before you change a function's parameters, find every call node to it in every graph, live or dead.
- **`remove_function_param` then `add_function_param` with the same name gives `Line1`** until the Blueprint compiles. Remove the new one and add it again to get the name back; the entry node then reads `Verb, Item, Target, Line`.
- **A call node made with `create_node` before a compile has the skeleton's old pins** (`Line1`). Delete it, compile, and create it again.
- **`execute_tool_script` may return a tool's error after later steps already ran.** One script that compiled (and failed) went on to create and wire a node, though the script reported only the compile error. Read the graph again after any error.
- **`save_assets` returns false while a game window (`-game`) launched on the project is still open.** Close that window first.
- **`LevelEditorPlaySettings`' saved window size on this PC is 3434 × 1352**, which is why T58's and T62's PIE windows opened maximized. Set `newWindowWidth` 1600, `newWindowHeight` 900, `newWindowPosition` (100, 100) before `StartPIE` with `playMode` `PlayMode_InEditorFloating`, and put them back after (done).
- **The auto-import exclusion for `NHOS/Data/*` held after the editor restart** this time (`AutoReimportDirectorySettings` read back with both wildcards), so no T71 fix was needed and no import note came up while the JSON files changed.
