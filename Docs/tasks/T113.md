- **Installs, with my person's OK:** ffmpeg 9.0.2 (`winget install Gyan.FFmpeg`; it lands in `%LOCALAPPDATA%\Microsoft\WinGet\Links`, which a shell started before the install doesn't have on its PATH) and Pillow 13.0.0 (`pip install pillow`).
- **The game's sound comes from Unreal's submix recording, not a loopback device.** This PC has no Stereo Mix, and a loopback would also catch the other sessions' editors. `UAudioMixerBlueprintLibrary` is `unreal.AudioMixerLibrary` in Python (`start_recording_output`, `stop_recording_output`); no console command records in a `-game` window, so recordings run in PIE in a second editor.
- **The engine mutes a window without focus** (`UnfocusedVolumeMultiplier=0` in `BaseEngine.ini`), which would make the recording silent. `au.DisableAppVolume 1` turns that off for the session.
- **ffmpeg's `gfxcapture` records an editor's PIE window by its HWND,** even under other windows, without the cursor. PIE draws its own window frame: in a 1920 × 1080 PIE window the client is 1926 × 1120 and the picture sits at x 3, y 36. ffmpeg rebases a lavfi input's timestamps to 0 unless it gets `-copyts`.
- **Line-up checked:** a click's sound and its picture change landed 7 ms apart, inside one frame at 60 fps.
- **With four editors on the RTX 3060, the engine drew a red "Video memory has been exhausted" note on the PIE screen.** `DisableAllScreenMessages` hides it; the recording script sets it. Shoot with as few editors open as possible.
- **`LevelEditorPlaySettings` isn't exposed to Python** (neither the class nor `new_window_width`). MCP's `ConfigSettingsToolset.SetSectionProperties` on Editor > LevelEditor > PlayIn sets the PIE window's size and place. It saves to that checkout's `Saved/Config`, outside git.
- **For T119:** my worktree's second editor logged `M_GlowStickSword: Failed to compile Material for platform PCD3D_SM6, Default Material will be used in game`, so that prop shows the default material in PIE on this PC too, not only in the packaged game.
- **The title port matches the Mac's:** `tools/cover_title.py` on `cover_art/art.png` with `--crop-x 23` is within a mean pixel difference of 0.7 (of 255) of `cover_art/cover_full.png`.
