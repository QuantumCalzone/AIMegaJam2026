# No Humans On Set: UI style

The UI direction lives in the design doc, not here: the **UI** section of [Art Inspiration](Design/ArtInspiration.md#ui) (see [GameDesign.md](GameDesign.md)). It sets the concept, the layout, the palette by role, the type scale, each component's look and states, the focus and next action on each screen, the motion times, and the rules every screen passes.

- **In the game,** the style Blueprint that T32 builds holds those values, and the widgets read them from it.
- **To change a value,** edit the doc first, after QuantumCalzone's OK, then the style Blueprint. Don't restate the doc in this file.
- **History:** a T32 prep draft of this file (commit `eb882ac`) set its own palette. The doc replaces it. The draft's list of widget names, and the facts it gathered from the task files, may still help T32.
